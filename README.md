# Jungle Rush: Temple Adventure

A Colorful Endless Runner Game Built with HTML, CSS, and JavaScript.

Jungle Rush is a fun endless runner game inspired by games like Temple Run. Run through a vibrant jungle, dodge obstacles, collect coins, and try to achieve the highest score.

## Features

- Colorful jungle environment and temple-inspired background
- Player movement across three lanes
- Coin collection and score tracking
- Multiple obstacles to avoid
- Jump and slide mechanics
- Increasing game speed
- Keyboard, button, and swipe controls
- Game Over screen with restart option
- Responsive interface for desktop and mobile screens

## Technologies Used

- HTML5 for the game structure
- CSS3 for styling, gradients, animations, and responsive design
- JavaScript for game logic, movement, collision detection, and scoring
- HTML Canvas API for drawing the game environment and obstacles

## How to Run the Game

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all three files are in the same folder.
4. Open `index.html` using Live Server or your web browser.
5. Click the Start Adventure button to begin playing.

## Game Controls

| Key | Action |
|---|---|
| Left Arrow or A | Move left |
| Right Arrow or D | Move right |
| Up Arrow or Space | Jump |
| Down Arrow or S | Slide |

On mobile devices, use the on-screen control buttons or swipe on the game screen.

## Objective

- Avoid obstacles on the jungle path.
- Jump over rocks and barriers.
- Slide under logs.
- Collect coins to increase your score.
- Survive as long as possible and beat your personal best.
